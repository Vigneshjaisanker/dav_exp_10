# Experiment: Data Visualization – Normal Curves on UCI Diabetes Dataset

## Aim

To visualize the distribution of Glucose and BMI values in the UCI Diabetes Dataset using histograms, kernel density estimation, and normal distribution curves.

## Objective

The objective of this experiment is to understand the distribution of numerical variables in the UCI Diabetes Dataset and compare their observed distributions with normal probability curves.

## Dataset

The experiment uses:

- UCI Diabetes Dataset

## Features Used

- Glucose
- BMI

## Topics Covered

- Data Visualization
- Histogram
- Kernel Density Estimation (KDE)
- Normal Distribution
- Mean and Standard Deviation
- Distribution Analysis
- Statistical Visualization

## Methodology

The following steps are performed:

1. Import the required Python libraries.
2. Load the UCI Diabetes Dataset.
3. Select the Glucose and BMI variables.
4. Plot histograms with KDE curves.
5. Calculate the mean and standard deviation of each variable.
6. Generate normal probability density curves.
7. Overlay the normal curves on the respective distributions.
8. Visualize and interpret the results.

## Data Visualization

### Glucose Distribution

A histogram and KDE curve are plotted for the **Glucose** variable. A normal distribution curve is generated using the mean and standard deviation of the Glucose values.

### BMI Distribution

A histogram and KDE curve are plotted for the **BMI** variable. A normal distribution curve is generated using the mean and standard deviation of the BMI values.

## Learning Outcomes

After completing this experiment, the learner will be able to:

- Understand data visualization techniques.
- Plot histograms for numerical data.
- Use KDE to visualize data distributions.
- Generate normal distribution curves.
- Calculate and use mean and standard deviation.
- Compare observed data distributions with normal curves.
- Interpret statistical distributions visually.

## Result

Normal distribution curves were successfully plotted for **Glucose** and **BMI** in the UCI Diabetes Dataset. The visualizations provide an understanding of the distribution and spread of the selected numerical variables.

## Conclusion

This experiment demonstrates the use of statistical visualization techniques to analyze numerical data. Histograms, KDE curves, and normal distribution curves help in understanding the shape, spread, and distribution characteristics of Glucose and BMI values in the UCI Diabetes Dataset.
